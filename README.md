# The Agentic Marketing Team

A 10-slide deck for opening a conversation with Superteam Balkan: what I learned running marketing as one human directing a team of agents, and what it could mean for Solana teams. Served at https://tituscapilnean.ro/agentic-marketing/ via GitHub Pages.

Plain static HTML, CSS and JS. No build step. GitHub Pages serves the repo root from `main`.

```
index.html          the deck (arrows, space or click to move, F fullscreen, N notes, #3 opens slide 3)
assets/deck.css     styles, fixed 1920x1080 stage scaled to the window
assets/deck.js      navigation and scaling
assets/favicon.svg  icon in the tituscapilnean.ro palette
```

Speaker notes live in each slide's `data-notes` attribute. Bump the `?v=` query on the stylesheet or script whenever it changes, or the CDN keeps serving the old one.

The page is `noindex` while the conversation is early. Figures come from one company, April to September 2026, rounded and shared without naming it.
